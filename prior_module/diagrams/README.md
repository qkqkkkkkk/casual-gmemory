# Prior Module Diagrams

The three SVG files are vector diagrams corresponding to the standalone
implementation:

- reliability_prior.svg: source replay, content fidelity, joint Y_r, and the
  Beta-based ReliabilityPrior.
- behavior_prior.svg: treatment/control Agent forwards, CanonicalAction, and
  ordered D_env distance for d0.
- utility_prior.svg: paired team branches, reward delta, and the three-class
  u0 predictor.

They can be opened directly in a browser or imported into presentation
software without rasterization.
